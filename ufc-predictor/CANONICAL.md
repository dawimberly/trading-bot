# Canonical UFC project

**Edit and build here:** `C:\UFC-Predictor`

This folder is a **synced mirror** of the standalone install. Do not treat it as a second source of truth.

After changes in `C:\UFC-Predictor`, run:

```powershell
cd C:\UFC-Predictor
powershell -File scripts\consolidate_ufc.ps1
```

Dashboard EXE: `C:\UFC-Predictor\dist\ufc-dashboard.exe`  
`.env`: `C:\UFC-Predictor\.env`
